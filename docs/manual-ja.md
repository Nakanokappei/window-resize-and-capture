## はじめに

1. **WindowsResizeCapture.exe** を実行します。スプラッシュ画面が一瞬表示されます。
2. アプリのアイコンが **システムトレイ**（タスクバー右下の通知領域）に表示されます。
3. トレイアイコンをクリックしてメニューを開きます。

> **注意:** 特別な権限は不要です。起動後すぐに使用できます。

## ウィンドウのリサイズ

### 操作手順

1. システムトレイの **Window Resize & Capture アイコン** をクリックします。
2. **「リサイズ」** にカーソルを合わせると、ウィンドウ一覧が表示されます。
3. 現在開いているすべてのウィンドウが **アプリケーションアイコン** と共に **[アプリ名] ウィンドウタイトル** の形式で一覧表示されます。長いタイトルは自動的に省略されます。
4. ウィンドウにカーソルを合わせると、利用可能なプリセットサイズが表示されます。
5. サイズをクリックすると、ウィンドウが即座にリサイズされます。

### サイズの表示形式

メニュー内の各サイズは以下のように表示されます。

```
1920 x 1080          Full HD
```

- **左側:** 幅 x 高さ（ピクセル単位）
- **右側:** ラベル（規格名）、グレーで表示

### 画面サイズを超えるプリセット

プリセットサイズがウィンドウのあるディスプレイの解像度を超える場合、そのサイズは **グレーアウトされ選択できません**。これにより、ウィンドウが画面の境界を超えてリサイズされることを防ぎます。

## 設定

Window Resize & Capture のトレイアイコンをクリックし、**「設定...」** を選択して設定画面を開きます。

### 内蔵サイズ

アプリには 12 種類の内蔵プリセットサイズが含まれています。

| サイズ | ラベル |
|--------|--------|
| 3840 x 2160 | 4K UHD |
| 2560 x 1440 | QHD |
| 1920 x 1200 | WUXGA |
| 1920 x 1080 | Full HD |
| 1680 x 1050 | WSXGA+ |
| 1600 x 900 | HD+ |
| 1440 x 900 | WXGA+ |
| 1366 x 768 | WXGA |
| 1280 x 1024 | SXGA |
| 1280 x 720 | HD |
| 1024 x 768 | XGA |
| 800 x 600 | SVGA |

内蔵サイズは削除・編集できません。

### カスタムサイズ

独自のサイズを追加できます。

1. **幅** と **高さ** をピクセル単位で入力します。
2. **「追加」** をクリックします。
3. 新しいサイズがカスタムリストに追加され、リサイズメニューですぐに使用可能になります。

カスタムサイズを削除するには、該当サイズの横にある **「削除」** ボタンをクリックします。

### ログイン時に起動

**「ログイン時に起動」** をオンにすると、Windows にログインした際に Window Resize & Capture が自動的に起動します。

### キャプチャ

**「リサイズ後にキャプチャする」** をオンにすると、リサイズ完了後に自動的にウィンドウをキャプチャします。

有効にすると、以下のオプションが利用可能になります。

- **ファイルに保存** — キャプチャした画像を PNG ファイルとして指定フォルダに保存します。
  > **ファイル名の形式:** `MMddHHmmss_アプリ名_ウィンドウタイトル.png`（例: `0227193012_chrome_Google.png`）。記号は除去され、英数字とアンダースコアのみ使用されます。
- **クリップボードにコピー** — キャプチャした画像をクリップボードにコピーし、他のアプリに貼り付けることができます。

両方のオプションは個別に有効にできます。

## トラブルシューティング

### リサイズに失敗しました

「リサイズに失敗しました」というアラートが表示される場合、以下の原因が考えられます。

- 対象のウィンドウが外部からのリサイズに対応していない。
- ウィンドウが **フルスクリーンモード** になっている（**F11** キーまたは **Esc** キーで解除してください）。

### ウィンドウが一覧に表示されない

リサイズメニューには、以下の条件を満たすウィンドウのみが表示されます。

- 現在画面上に表示されている
- タイトルバーを持っている
- Window Resize & Capture 自身のウィンドウでない

最小化されたウィンドウは一覧に表示されません。

### キャプチャされない

画像がキャプチャされない場合は、以下を確認してください。

- 設定で **「ファイルに保存」** または **「クリップボードにコピー」** の少なくとも一方が有効になっていることを確認してください。
- ファイルに保存する場合、保存先フォルダが存在し、書き込み可能であることを確認してください。
