# The line that admits the taskbar in these pictures is drawn rather than
# photographed - the band itself, the icons on it, the search box and the clock.
# The app's own menu and settings window are the real ones.
#
# One [tag] section per language, one line each. A language with no section
# falls back to [en].
#
# The taskbar, and only the taskbar. The wallpaper was named too for a while,
# which says nothing a reader does not already assume about a wallpaper; the
# taskbar is the part of the picture that looks like a photograph of Windows and
# is not one.
#
# The word for it is the one each language's own copy uses, which is the one
# Windows uses in that language: Taskleiste, barra delle applicazioni,
# 작업 표시줄, 工作列.
#
# This is not one sentence translated sixteen times. Every language has its own
# convention for "this is a stand-in, not the thing itself", and the word that
# carries it differs in each: the German Symbolbild, the Chinese 示意图, the
# Korean 연출된 화면, the Japanese イメージ. Translating any of them literally
# into another language says something else - the English "image" would only be
# stating that a picture is a picture.
