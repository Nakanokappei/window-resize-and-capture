# The cast of windows the studio pretends is open, per language.
#
# The real enumeration lists whatever the operator happens to have running, so
# every language's picture would differ and their own documents would appear
# in a store listing. This file stands in for it.
#
# Format: a [tag] line starts a language, then ten lines in order:
#   five browser window titles, the Notepad title, the Paint title,
#   then the three application names shown on the group headings:
#   browser, notepad, paint.
#
# The application names are the everyday words for the programs, not the names
# on their title bars. A listing picture is read by someone deciding whether
# to install; "Browser" tells them more than a product name would, and it does
# not put another company's brand in our picture.
#
# Lines starting with # are ignored. A language with no section falls back to
# [en]. A section without exactly ten lines is dropped rather than used short.
#
# The titles are deliberately dull. A listing picture should not advertise
# anybody else's site, and a title that draws the eye competes with the menu
# the picture is about. These are provisional; replace them if better ones
# come along.
