# The cast of windows the studio pretends is open, per language.
#
# The real enumeration lists whatever the operator happens to have running, so
# every language's picture would differ and their own documents would appear
# in a store listing. This file stands in for it.
#
# Format: a [tag] line starts a language, then ten lines in order:
#   five browser window titles, the Notepad window title, the File Explorer
#   window title, then the three application names shown on the group headings:
#   browser, notepad, file explorer.
#
# The browser is called by the everyday word for it rather than by a product
# name: a listing picture is read by someone deciding whether to install, and
# "Browser" tells them more while keeping another company's brand out of the
# picture. Notepad and File Explorer are Windows' own and are named, because a
# menu item reading "Untitled" looks like a window nobody can identify.
#
# Lines starting with # are ignored. A language with no section falls back to
# [en]. A section without exactly ten lines is dropped rather than used short.
#
# The browser titles are deliberately dull. A listing picture should not
# advertise anybody else's site, and a title that draws the eye competes with
# the menu the picture is about. These are provisional; replace them if better
# ones come along.
